Задача: Создать контракт для простого API управления библиотекой (Library API).

Тебе нужно описать базовую информацию и три эндпоинта (метода). Постарайся сделать это через визуальный редактор (создавая модели, поля и методы кликами мышки), а не просто писать код руками — так ты почувствуешь возможности Stoplight.

Требования к контракту:
Общая информация:
Название API: Library API
Версия: 1.0.0
Протокол: http (или просто без указания сервера).

Эндпоинт 1: Получить список всех книг
Метод: GET
Путь: /books
Параметр запроса (Query Parameter):
Имя: year
Тип: integer
Описание: Фильтр по году публикации (необязательный).
Ответ (Response 200):
Тип содержимого: application/json
Тело: Массив объектов книг.

Эндпоинт 2: Добавить новую книгу
Метод: POST
Путь: /books
Тело запроса (Request Body):
Тип содержимого: application/json

Объект книги должен содержать поля:
- title (string) — обязательное.
- author (string) — обязательное.
- year (integer) — обязательное.
Ответ (Response 201):
Сообщение об успешном создании.

Эндпоинт 3: Получить конкретную книгу
Метод: GET
Путь: /books/{bookId}
Параметр пути (Path Parameter):
Имя: bookId
Тип: string
Ответы:
200 — вернуть объект книги.
404 — если книга не найдена.
